## 👋 Quiénes somos

Ayudamos a negocios a dar el salto digital: desde una web o app a medida, hasta soluciones de software pensadas para su día a día.

Además, desarrollamos productos propios que nacen de problemas reales que detectamos trabajando con nuestros clientes — y seguimos explorando y validando nuevas ideas de forma constante.

## 🚀 Lo que hacemos

- **Desarrollo a medida** — webs, apps y software adaptado a cada negocio
- **Productos propios** — herramientas SaaS creadas y mantenidas por nosotros
- **Nuevas ideas** — probamos y validamos conceptos antes de convertirlos en producto
